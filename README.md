👩🏻‍💻Installation & Launch
1. Install Xcode.
2. Create a folder for the project and open Terminal.
3. Navigate to your folder and run: git clone https://github.com/SanjiS86/USTYieldCurveTracker.git
4. Open the cloned folder and double-click YieldCurveApp.xcodeproj to launch it in Xcode.

👩🏻‍💻What the App Provides

Compare the U.S. Treasury yield curve across any two dates you choose. Visualizing the curve’s shape and its changes over time helps you assess market expectations and investor sentiment.

👩🏻‍💻How You Can Use It

1. Select fixed-income strategies aligned with the prevailing curve shape.
2. Inform equity selection—decide between growth, income, or value stocks.
3. Gauge overall market health and investor confidence.
4. Plan long-term entry and exit points with greater context.
